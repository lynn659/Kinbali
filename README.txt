Kin Bali Massage 网站 — 上线说明
================================

文件夹内容
- index.html        首页
- treatments.html   Treatments 目录页
  （两个文件内容一样，只是打开时先显示的页面不同；两页切换不会重新加载，背景音乐不会中断）
- assets/           图片、视频、音效、背景音乐、字体、CSS、JS

这是纯静态网站，整个文件夹一起上传即可，保持 assets 文件夹结构不变。

更新已上线的网站（Netlify）
1. 打开 https://app.netlify.com 进入你的网站。
2. 点 Deploys。
3. 把新的 kinbali-site 文件夹（解压后的文件夹，不是 zip）拖进页面下方的上传框。
4. 等 1 分钟，刷新你的网站即可（如果看到旧版，按 Ctrl + F5 强制刷新）。

其他主机（cPanel 等）：把文件夹里的全部内容上传到 public_html，覆盖旧文件。
